# Gold sets

Hand-labelled, one JSON object per line. `python -m evals.run_all` reads whichever exist.
Nothing here is generated by a model, because these files are what the models are graded against.

## `normalization.jsonl` — target ≥ 0.92 top-1, abstention allowed

What Omni read off a real label, and the RXCUI a human checked against the bottle.

```json
{"id": "n001", "raw_text": "METF0RMIN HCL 500MG", "rxcui": "RXCUI:6809"}
```

## `severity.jsonl` — target precision@5 ≥ 0.80

A medication list as codes, and the pairs a reviewer judged worth raising.

```json
{"id": "s001", "codes": ["RXCUI:11289", "RXCUI:83367", "RXCUI:9997"], "relevant": [["RXCUI:11289", "RXCUI:83367"]]}
```

## `citations.jsonl` — target ≥ 0.95

A sentence Tessera rendered, the span it cited, and a human verdict on whether the span supports it.
Audits the automated entailment check, which uses the same model family as the writer.

```json
{"id": "c001", "sentence": "…", "span_id": "…", "supported": true}
```

No photographs of real people's prescriptions belong in this repository. Record the OCR text
and the verified code, not the image.
